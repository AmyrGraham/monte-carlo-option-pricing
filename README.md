# Monte Carlo Option Pricing

A Python project that uses Monte Carlo simulation to estimate the price of a European call option.

## Overview

This project simulates possible future stock prices using Geometric Brownian Motion (GBM). The simulated stock prices are then used to estimate the price of a European call option using Monte Carlo methods.

The Monte Carlo estimate is compared with the Black-Scholes analytical price.

## Methods Used

- Geometric Brownian Motion
- Monte Carlo simulation
- European call option pricing
- Black-Scholes model
- Normal distribution
- Discounted expected payoff

## Results

The project simulated 10,000 possible future stock prices and calculated the corresponding European call option payoffs.

The Monte Carlo estimate was then compared with the analytical Black-Scholes price to evaluate the accuracy of the simulation.
